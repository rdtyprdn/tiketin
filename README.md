# tiketin
tiketin adalah aplikasi kiosk pemesanan tiket bioskop yang berfungsi untuk efisiensi kecepatan pemesanan tiket bioskop. Tiketin berguna untuk diletakkan di kiosk

## Cara menjalankan
Lihat [SETUP.md](SETUP.md) untuk langkah install (JDK 21, Maven, MySQL), membuat database, mengisi `db.properties`, dan menjalankan `mvn clean javafx:run`.
